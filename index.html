NerdMiner CYD · รุ่นไลท์

ติดตั้ง NerdMiner ผ่านเบราว์เซอร์

ใช้ติดตั้งครั้งแรกหรืออัปเดตเป็นรุ่นใหม่ ไม่ต้องลงโปรแกรม เสียบสาย USB แล้วกดปุ่มด้านล่าง

เฟิร์มแวร์ 2.0.0-lite-rc.3

เบราว์เซอร์นี้ติดตั้งไม่ได้
ใช้ Google Chrome หรือ Microsoft Edge บนคอมพิวเตอร์ (Windows, Mac, Linux) iPhone และ iPad ใช้ไม่ได้ทุกเบราว์เซอร์

ก่อนกดติดตั้ง

  1. เปิดหน้านี้ด้วย Chrome หรือ Edge บนคอมพิวเตอร์
  2. เสียบบอร์ดเข้าคอมด้วยสาย USB ที่ส่งข้อมูลได้ (สายชาร์จอย่างเดียวคอมจะมองไม่เห็นบอร์ด)
  3. ปิดโปรแกรมอื่นที่อาจใช้พอร์ตอยู่ เช่น Arduino IDE หรือ Serial Monitor

เลือกตามจอของคุณ แล้วกดติดตั้ง

จอปกติ (HW-458) บอร์ดส่วนใหญ่ ถ้าไม่แน่ใจให้เลือกอันนี้ก่อน ต้องเปิดผ่าน https
จอ TPM408 จอที่ด้านข้างพิมพ์ว่า “TPM408-2.8” ซึ่งต้องกลับสี ต้องเปิดผ่าน https
  1. กดปุ่มแล้วเลือกพอร์ตของบอร์ด (มักชื่อ USB-SERIAL CH340 หรือ USB Serial) แล้วกด Connect
  2. กด Install แล้วรอ 1–2 นาทีจนขึ้นว่าเสร็จ อย่าถอดสายระหว่างนี้
  3. กดปุ่ม RST บนบอร์ด หรือถอดสายแล้วเสียบใหม่
ค่าที่ตั้งไว้ไม่หาย
ถ้าหน้าติดตั้งถามว่าจะลบเครื่อง (Erase) ให้เว้นไว้ไม่ต้องติ๊ก WiFi ที่อยู่ BTC และค่าอื่นๆ จะยังอยู่ ติ๊กเฉพาะเมื่ออยากล้างเครื่องให้เหมือนใหม่
ถ้าแฟลชแล้วสีจอเพี้ยนเหมือนฟิล์มเนกาทีฟ
กลับมาติดตั้งอีกปุ่มหนึ่ง

หาพอร์ตไม่เจอ

  1. ลองเปลี่ยนสาย USB หรือช่อง USB บนคอม
  2. Windows อาจต้องลงไดรเวอร์ CH340 (ค้นหา “CH340 driver” จากเว็บผู้ผลิต WCH)
  3. บางบอร์ดต้องกดปุ่ม BOOT ค้างไว้ตอนเริ่มติดตั้ง
